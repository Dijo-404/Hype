# Hyprland Keybindings

| Keybinding | Action | Description |
| :--- | :--- | :--- |
| **Window Management** | | |
| `SUPER + Q` | `killactive` | Close active window |
| `CTRL + Q` | `killactive` | Close active window |
| `ALT + F4` | `killactive` | Close active window |
| `SUPER + Delete` | `exit` | Exit Hyprland |
| `SUPER + W` | `togglefloating` | Toggle floating mode |
| `SUPER + G` | `togglegroup` | Toggle window group |
| `SHIFT + F11` | `fullscreen` | Toggle fullscreen |
| `SUPER + L` | `hyprlock` | Lock screen |
| `SUPER + SHIFT + F` | `pin` | Pin window |
| `ALT + CTRL + Delete` | `wlogout` | Logout menu |
| `ALT + Right Ctrl` | `pkill waybar || waybar` | Reload Waybar |
| `SUPER + J` | `togglesplit` | Toggle split direction |
| **Focus** | | |
| `SUPER + Arrow Keys` | `movefocus` | Move focus |
| `ALT + Tab` | `cyclenext` | Cycle focus |
| **Resize** | | |
| `SUPER + SHIFT + Arrow Keys` | `resizeactive` | Resize active window |
| **Move Window** | | |
| `SUPER + CTRL + SHIFT + Arrows` | `movewindow` | Move window |
| **Applications** | | |
| `SUPER + T` | `alacritty` | Terminal |
| `SUPER + E` | `dolphin` | File Manager |
| `SUPER + C` | `nvim` | Text Editor |
| `SUPER + B` | `firefox` | Browser |
| `CTRL + SHIFT + Esc` | `htop` | System Monitor |
| `SUPER + A` | `rofi -show drun` | Application Launcher |
| `SUPER + Tab` | `rofi -show window` | Window Switcher |
| `SUPER + SHIFT + E` | `rofi -show filebrowser` | File Browser |
| `SUPER + /` | `rofi -show keys` | Show Keybindings |
| `SUPER + .` | `rofi emoji` | Emoji Picker |
| `SUPER + V` | `cliphist` | Clipboard History |
| **Audio** | | |
| `F10` / `Mute` | `mute` | Mute Audio |
| `F11` / `Vol Down` | `down` | Volume Down |
| `F12` / `Vol Up` | `up` | Volume Up |
| **Brightness** | | |
| `F5` / `Bright Down` | `down` | Brightness Down |
| `F6` / `Bright Up` | `up` | Brightness Up |
| **Workspaces** | | |
| `SUPER + 0-9` | `workspace` | Switch to workspace |
| `SUPER + S` | `special workspace` | Toggle Special Workspace |
| `SUPER + SHIFT + S` | `movetoworkspace` | Move to Special Workspace |
| **Screenshot** | | |
| `SUPER + SHIFT + P` | `hyprpicker` | Color Picker |
| `SUPER + P` | `grimblast area` | Screenshot Area |
| `Print` | `grimblast screen` | Screenshot Screen |
