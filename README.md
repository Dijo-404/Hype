## ✨ Features

- **Window Manager**: Hyprland
- **Bar**: Waybar (Everforest Theme)
- **Terminal**: Kitty
- **Launcher**: Rofi
- **Notifications**: Dunst
- **Shell**: Zsh + Powerlevel10k
- **System**: Custom GRUB, Plymouth, and SDDM themes.
